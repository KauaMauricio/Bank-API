# 💸 Schedule Transfer

Sistema web para **agendamento e gerenciamento de transferências financeiras**, desenvolvido para praticar meus conhecimentos de desenvolvimento Full Stack.

## 🚀 Tecnologias

**Backend**
- Java 11
- Spring Boot 2.7
- Spring Data JPA
- H2 Database

**Frontend**
- Angular 21
- TypeScript
- Bootstrap

## ✨ Funcionalidades

- 📋 Listagem de transferências agendadas
- 💰 Cálculo de taxas e valores
- 📅 Agendamento de transferências
- 📊 Dashboard com resumo financeiro
- ❌ Cancelamento de transferências

## ⚙️ Como executar

**1. Backend**

Entre na pasta do backend e execute:

```bash
mvn spring-boot:run
```

API disponível em: `http://localhost:8080`

**2. Frontend**

Entre na pasta do frontend e execute:

```bash
npm install
npm start
```

Aplicação disponível em: `http://localhost:4200`

> Pré-requisitos: Java 11, Maven, Node.js e npm.

## 🎯 Objetivo

Projeto desenvolvido para aprimorar conhecimentos em **Java, Spring Boot, Angular, APIs REST e integração entre frontend e backend**.
